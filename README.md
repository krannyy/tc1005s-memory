# tc1005s-memory

Juego de Memoria de freegames, modificado para la evidencia de TC1005S (Actividad 5).

Owner del repositorio: Jaime Samuel García Manzano (krannyy). Fork: Angel Barush (thenewbaru).

## Contenido
- `memory.py`: el juego.
- `README.md`: este archivo.

## Cómo correrlo
```
pip install freegames
python3 memory.py
```
Se hace clic en los cuadros para destaparlos y encontrar las parejas.
